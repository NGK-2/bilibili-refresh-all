# B站首页 换一换 刷新全部可见视频（带历史）

B 站首页原生的「换一换」只会刷新最上面几行，往下的视频不会变。这个油猴脚本接管了「换一换」，**一次把屏幕上能看到的所有视频卡片都换掉**，并且支持 **← / → 回退和前进** 到之前换过的内容，可以替代单独的“换一换历史”类插件。

## 功能

- **刷新全部可见视频**：顶部原生区域每次都换；下方卡片只要上边缘出现在屏幕内就一起换。看到几行就换几行。
- **换一换历史**：「换一换」按钮下方增加 ← → 按钮，可回退 / 前进，最多保存 30 步。回退到第一步时恢复的是 B 站原始卡片（悬停预览等功能完整）。
- **个性化推荐不变**：使用 B 站官方推荐接口（带 WBI 签名）和你自己的登录状态，推荐内容和原生一致。
- **自动去重**：新换上的视频不会和当前屏幕上已有的重复。
- **不破坏页面**：原生卡片只隐藏、不修改，下拉加载更多照常工作。
- **未登录也能用**：找不到原生「换一换」按钮时，右下角会出现「← 换一换 →」悬浮按钮。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey 等兼容的用户脚本管理器）。
2. 点击安装：[bilibili-refresh-all.user.js](https://raw.githubusercontent.com/NGK-2/bilibili-refresh-all/main/bilibili-refresh-all.user.js)
3. 刷新 B 站首页即可。

> 如果你装了其他“换一换历史”类插件 / 脚本，请先停用，避免两者同时接管按钮。

## 设置

在脚本开头的「配置」部分修改：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `EXTRA_PX` | `0` | 判定“可见”时在屏幕底部之外多算的像素。调大（如 `200`）可以把即将露出的下一行也一起换掉 |
| `MAX_HISTORY` | `30` | 最多保存的历史步数 |
| `SHOW_FALLBACK_BUTTON` | `true` | 找不到原生按钮时是否显示右下角悬浮按钮 |

## 已知限制

- 脚本换上的卡片没有鼠标悬停视频预览和“稍后再看”按钮，点击打开视频正常。
- 下方原本的直播、广告等卡片如果在可见范围内，会被换成普通视频。
- 依赖 B 站首页当前的页面结构，B 站改版后可能需要更新。

## 调试

在浏览器控制台中可以调用：

- `__brrRefresh()`：执行一次刷新
- `__brrGo(-1)` / `__brrGo(1)`：回退 / 前进
